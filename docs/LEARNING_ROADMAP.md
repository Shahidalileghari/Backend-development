# Learning roadmap
1. Web foundations: DNS, TCP, TLS, HTTP, cookies, caching.
2. JavaScript: scope, closures, prototypes, modules, promises, async/await.
3. Node: event loop, libuv, streams, buffers, workers, process lifecycle.
4. Express: middleware, routers, validation, errors, layered architecture.
5. PostgreSQL: ER modelling, normalization, joins, constraints, indexes, transactions.
6. Auth: password hashing, sessions, JWT, refresh rotation, RBAC and ownership.
7. API design: pagination, filtering, versioning, OpenAPI, idempotency.
8. Security: OWASP API risks, CORS, CSRF, SSRF, rate limiting, secrets.
9. Testing: unit, integration, API, contract and end-to-end.
10. Operations: Docker, CI, logs, metrics, tracing, health and shutdown.
11. Advanced patterns: Redis, queues, outbox, webhooks, uploads, realtime.
12. System design: modular monoliths, resilience, scaling and multi-tenancy.
Suggested pace: 10–14 weeks at 1–2 focused hours daily. Build a working artifact at every stage.
