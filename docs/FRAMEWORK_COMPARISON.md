# Express vs Fastify vs NestJS
| Framework | Strength | Typical fit |
|---|---|---|
| Express | Minimal, mature middleware ecosystem | Learn HTTP fundamentals; flexible services |
| Fastify | Schema-oriented, performance focus, plugin encapsulation | Teams needing explicit schemas and throughput |
| NestJS | Opinionated modules, DI, decorators, TypeScript-first | Larger applications needing consistent conventions |
This course uses Express as its main stack, then asks learners to rebuild a feature in Fastify or NestJS to compare trade-offs. Framework selection depends on team, maintainability, ecosystem and operations—not benchmark headlines alone.
