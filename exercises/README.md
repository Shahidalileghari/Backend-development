# Exercises
## Beginner
1. Build GET `/books` and `/books/:id` with an in-memory repository.
2. Add request IDs to success and error responses.
3. Validate registration input and return field-level errors.
4. Add bounded limit/offset pagination.
## Intermediate
5. Design users/projects/project_members tables with constraints.
6. Implement Argon2id password hashing and secure sessions.
7. Prevent users from reading another user's project.
8. Add PostgreSQL integration tests.
9. Create an order and line items in one transaction.
10. Add structured logs and graceful shutdown.
## Advanced
11. Implement idempotent payment-intent creation.
12. Implement a transactional outbox and idempotent worker.
13. Add Redis caching and stampede protection.
14. Design tenant isolation and prove it with tests.
15. Publish OpenAPI and compatibility checks.
